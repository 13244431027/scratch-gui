# 造像工作室（Studio Paint）

给 Scratch 造像编辑器（scratch-paint）加一套专业图像处理能力，功能与交互参考开源图像编辑器
[Compositor](https://github.com/robbietilton/Compositor)：调整、滤镜、图层效果、变换与图层堆栈。

**不改 scratch-paint 源码**，全部能力通过 addon 公开接口（`addon.tab`）+ paper.js 实现。

## 启用

1. 打开造像（costume）页；
2. 在画布右下角的按钮条上会出现一个调色盘图标，点击打开右侧面板；
3. 面板默认收起状态在插件设置里（扩展 → 造像工作室）可随时开关。

> 滤镜只在**位图模式**下工作。若当前造型是矢量，面板顶部会提示先点「转位图」。

## 功能

### 调整
色阶（RGB/单通道，含自动与重置）、曲线（可拖动控制点的曲线编辑器，支持四个通道）、
曝光（EV / 偏移 / 伽马）、色相·饱和度（含单色化）、黑白（六色权重）、
色彩平衡（阴影 / 中间调 / 高光，可保持明度）、渐变映射（三段渐变 + 反转）、颗粒、反相。

### 滤镜
高斯模糊（可分离盒式三次近似，O(n)）、动感模糊（角度 + 距离）、辉光（阈值 / 半径 / 强度，滤色叠加）、
锐化（USM）、色调对比（暗部 / 亮部 S 曲线）、添加噪点（正态 / 单色）、暗角、镜头校正（桶形畸变 / 色散 / 暗角）、像素化。

### 图层效果
描边（可切内侧）、投影、内阴影、外发光、内发光、颜色叠加。全部基于 alpha 蒙版运算，半透明边缘不会出现硬光晕。

### 变换
旋转（任意角度）、缩放（5%~400%，平滑或像素化两种重采样）、水平/垂直翻转、90° 步进旋转、
裁剪宽高（居中裁剪）、裁掉透明边、扩展画布一倍。

### 图层
自建图层栈（scratch-paint 本身只有一张位图）：新建空图层、从当前结果新建、复制、删除、上移/下移、向下合并，
每个图层可调可见性、不透明度与 16 种混合模式（含正片叠底、滤色、叠加、柔光、色相、明度等）。

### 直方图
明度 / RGB 通道直方图，实时随预览刷新；支持导出 PNG 与复制到剪贴板。

## 工作方式

- 面板的所有改动都基于「打开面板时的像素」重新计算，因此可以反复调整参数对比效果；
- 结果先以**预览**形式装回画布（不改工程）；
- 点「应用」才真正提交：走 scratch-paint 自己的 `onUpdateImage` 通道，等价于一次画笔操作，
  因此工程会被标记为已修改，并且**可以用 Ctrl+Z 撤销**；
- 点「取消预览」或关闭面板会丢弃预览；若中途在画布上画了新内容，插件不会覆盖你的修改。

## 目录

```
studiopaint/
├── _manifest_entry.js     插件清单
├── _runtime_entry.js      打包入口
├── userscript.js          按钮注入与面板生命周期
├── style.css              面板样式
├── lib/
│   ├── imaging.js         像素算法核心（调整 + 滤镜 + 直方图）
│   ├── effects.js         图层效果
│   ├── transform.js       变换 / 裁剪 / 尺寸
│   ├── layers.js          图层堆栈与混合模式
│   ├── paper-adapter.js   与 scratch-paint 的读写桥接
│   └── ui.js              面板、控件、曲线编辑器、直方图
└── tests/
    └── imaging.test.mjs   纯算法冒烟测试（Node 可直接跑）
```

## 测试

```sh
node src/addons/addons/studiopaint/tests/imaging.test.mjs
```

覆盖反相、色阶、曲线、模糊（含转置对称性，可抓方向索引错误）、动感模糊、辉光、锐化、暗角、
颗粒可复现性、色相旋转、曝光、直方图、像素化、描边、投影、颜色叠加，以及整条渲染管线。

UI 与 paper 交互需要在真实编辑器里手动验证（跑 `bun run start` 打开造像页）。
